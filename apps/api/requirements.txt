# `python-multipart` was removed deliberately, not by accident: nothing in this
# API parses multipart bodies. Uploads go browser -> Supabase Storage directly
# (the bytes never touch FastAPI), and every endpoint takes JSON. It had
# accumulated seven advisories, including two DoS issues in multipart parsing and
# a negative-Content-Length read in parse_form() — all in code paths this app
# never executes. An unused dependency cannot be reached, but it is still attack
# surface in the supply chain and noise in every future audit, so it is gone. If
# a multipart endpoint is ever added, FastAPI needs it back and it must be
# >= 0.0.31.
